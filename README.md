# 🏙️ Madrid — La Capital de España

Proyecto web creado por **Tu Nombre** como parte de un curso de desarrollo web, utilizando **Claude AI** de Anthropic.

## 📋 Descripción

Una página web estática e interactiva que presenta Madrid, incluyendo:

- **Qué visitar** — Los monumentos y museos más emblemáticos (Prado, Palacio Real, Retiro...)
- **Dónde comer** — Restaurantes y zonas gastronómicas imprescindibles
- **Dónde pasear** — Rutas y espacios al aire libre
- **Historia** — Línea temporal desde el siglo IX hasta hoy

## 🗂️ Estructura de archivos

```
madrid-web/
├── index.html   → Estructura y contenido de la web
├── style.css    → Estilos y diseño visual
├── script.js    → Interactividad (acordeones, animaciones)
└── README.md    → Este archivo
```

## 🛠️ Tecnologías utilizadas

- HTML5 semántico
- CSS3 (variables CSS, Grid, Flexbox, animaciones)
- JavaScript vanilla (Intersection Observer, eventos DOM)
- Google Fonts (Bebas Neue + Outfit)
- Imágenes de Wikimedia Commons (licencia Creative Commons)

## 🚀 Cómo ver la web

### En local
1. Descarga o clona el repositorio
2. Abre `index.html` en cualquier navegador moderno

### En GitHub Pages
1. Ve a **Settings → Pages** en tu repositorio
2. En *Branch*, selecciona `main` y la raíz `/`
3. Guarda y espera unos segundos — ¡tu web estará en línea!

## ✨ Funcionalidades

- Diseño **responsive** adaptado a móvil, tablet y escritorio
- **Acordeones interactivos** con fotos y descripciones de cada lugar
- **Línea temporal** animada con la historia de Madrid
- Animaciones de aparición al hacer **scroll**
- Navegación rápida desde el hero mediante **pills de ancla**
